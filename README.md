📘 Daily Planner

A soft sky-blue, aesthetic daily study planner built as a single HTML page. Write your plan every day, and it saves automatically in your browser. No login and no setup needed.

✨ Features
🎯 Today’s Goal and 🏆 Today’s Wins to start and end the day with purpose
⏰ Hourly study schedule from 4 AM to 11 PM
✅ Top 5 priorities, a to-do list, subjects to study and a Don’t Forget list
💗 Weekly study tracker for Focus, Notes, Practice, Revision, Reading and Mocks
🎀 Bow Tracker (Pomodoro timer) with 25 min focus, 5 min break, and a long break after 4 bows
💧 Water tracker, ⭐ day rating, 📝 notes and 🐻 “I’m proud of” section
📅 Date navigation to open, edit or rewrite any past day
💾 Autosave with a Save button and a Clear day option
🌙 Automatic dark mode and a mobile-friendly layout
🛠️ Built With

HTML, CSS and vanilla JavaScript (data saved with localStorage)

🚀 Usage

Open daily-planner.html in any browser and start planning.
